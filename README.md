## Overview

This repository documents a professional web application penetration test performed against **OWASP WebGoat** in a controlled laboratory environment.

The project follows the OWASP Web Security Testing Guide (WSTG) and demonstrates the methodology used during a real-world web application security assessment.

---

## Objectives

- Perform reconnaissance
- Map the application
- Test authentication
- Evaluate session management
- Identify common web vulnerabilities
- Document findings professionally
- Produce a penetration testing report
